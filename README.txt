Mishka hachette — стартовая PWA-сборка

Как открыть для теста:
1. Распакуйте архив.
2. Разместите содержимое папки на HTTPS-хостинге (например, статический хостинг).
3. Откройте адрес в Safari на iPhone.
4. Поделиться -> На экран Домой.

Возможности этой сборки:
- локальный список маркеров с добавлением/редактированием/удалением;
- стартовые ориентировочные палитры Languo Dark Skin и Gray Brown;
- создание раскрасок и страниц;
- статусы страниц и таймер;
- ввод символа Hachette и эталонного HEX, ранжирование ближайших маркеров;
- добавление фотографий (уменьшаются для экономии места);
- экспорт JSON-резервной копии.

Ограничения:
- Яндекс Диск пока НЕ подключён. Раздел облака — информационный; автоматическая синхронизация появится после настройки OAuth/API и безопасного серверного компонента.
- Guangna 168 не включена в эту сборку: исходная таблица цветов и созданный ранее файл палитры недоступны в текущей сессии. Не выдумываем номера и оттенки; их можно внести вручную или импортировать в следующей версии.
- Цвета Languo — ориентировочные цифровые образцы, не измеренные спектрофотометром.
- Процент сходства — ориентировочная визуальная метрика, не лабораторная оценка; при пополнении коллекции рекомендации пересчитываются.
- Данные пока хранятся локально в браузере. Делайте резервные копии.
